# AI use and provenance

AI assistance was used during project ideation, ecosystem review, and drafting/implementation of MoonBit code and documentation. Generated suggestions are treated as untrusted drafts: the project is expected to validate algorithmic behavior with explicit invariants, tests, formatting/interface checks, and CI. The project does not intentionally include AI-generated third-party source code or material of unknown provenance. The author remains responsible for review, license compliance, correctness, and maintenance.

This disclosure covers the project workflow; it does not imply that unimplemented or unverified capabilities are complete.
